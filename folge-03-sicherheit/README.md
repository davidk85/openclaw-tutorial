- Den Modus Geschützt für eine Unterhaltung einstellen

## Voraussetzungen

- Ein laufendes OpenClaw: [OpenClaw starten](../README.md#openclaw-starten)
- OpenClaw mit Ollama (Folge 1)

## Datenschutz

Ausgaben von Befehlen landen im Chat und gehen an das Modell. Mit Ollama bleibt das auf deinem Rechner, mit einem Cloud-Modell sieht der Anbieter, was ein Befehl ausgibt, also zum Beispiel Dateiinhalte. Keine Rechtsberatung.
