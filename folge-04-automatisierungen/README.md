# Folge 4: OpenClaw arbeitet nach Zeitplan

Automatisierungen anlegen, testen und pausieren

▶ Video: folgt

## Was du lernst

- Was eine Automatisierung in OpenClaw ist
- Prompt, Name und Zeitplan festlegen
- Einen Cron-Ausdruck lesen (0 7 * * 1-5)
- Eine Automatisierung sofort ausführen und das Ergebnis prüfen
- Eine Automatisierung pausieren

## Voraussetzungen

- Ein laufendes OpenClaw: [OpenClaw starten](../README.md#openclaw-starten)
- OpenClaw mit Ollama (Folge 1), Agent mit Profil (Folge 2)

## Datenschutz

Automatisierungen laufen ohne dich. Mit Ollama bleibt alles auf deinem Rechner. Mit einem Cloud-Modell gehen die gelesenen Dateien bei jedem Lauf an den Anbieter, auch nachts. Keine Rechtsberatung.
