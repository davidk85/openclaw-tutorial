# Folge 2: Dein erster OpenClaw-Agent

Name, Profil und die erste Aufgabe mit einer Datei

▶ Video: folgt

## Was du lernst

- Name und Emoji des Agenten in den Einstellungen festlegen
- In USER.md beschreiben, wer du bist und wie der Agent antworten soll
- Eine neue Unterhaltung beginnen und das Profil testen
- Den Agenten eine Datei im Arbeitsbereich anlegen lassen
- An der Werkzeug-Karte erkennen, was der Agent wirklich getan hat

## Voraussetzungen

- Ein laufendes OpenClaw: [OpenClaw starten](../README.md#openclaw-starten)
- OpenClaw mit Ollama (Folge 1)

## Datenschutz

Was in USER.md steht, schickt OpenClaw bei jeder Nachricht an das Modell. Mit Ollama bleibt das auf deinem Rechner, mit einem Cloud-Modell geht es an den Anbieter: dann keine vertraulichen oder personenbezogenen Angaben ohne passende Grundlage hineinschreiben. Keine Rechtsberatung.
